# DEFYOX — documentos legales

Este repositorio contiene las páginas legales públicas de DEFYOX.

- `privacidad.html`: política de privacidad, borrador pendiente de completar y validar.
- `eliminacion.html`: instrucciones para solicitar la eliminación de datos.

## Publicar con GitHub Pages
1. Abre `Viciooo4/defyox-legal`.
2. Ve a **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona `main` y `/(root)`.
5. Pulsa **Save** y espera a que se publique.

URLs previstas, válidas solo después de publicar y comprobar:
- https://viciooo4.github.io/defyox-legal/privacidad.html
- https://viciooo4.github.io/defyox-legal/eliminacion.html

No introduzcas las URLs en Meta hasta comprobar que ambas abren públicamente.
Consulta `CHECKLIST_ANTES_DE_PUBLICAR.txt` antes de publicar.
